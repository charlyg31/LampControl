Lamp Control
===========

Turn on lamps, powered rails and **shelves (étagères)** with flint/steel, WorldEdit, and more!

- Right-click a redstone lamp / powered rail with the control item (or empty hand with `lampcontrol.hand`) to switch it on/off without redstone.
- Right-click a shelf with the control item to switch its *powered* look on/off. Powered shelves facing the same way connect (3 max) and swap the hotbar like vanilla. Shelves need the item: an empty hand takes items off the shelf.
- `/lamp` or `//lamp` (WorldEdit selection) turns lamps and shelves on, `/lamp off` turns them off.

Requires Paper 26.3 and Java 25. Build with `mvn package`.

Bukkit-dev: [here](https://dev.bukkit.org/bukkit-plugins/lampcontrol/)
