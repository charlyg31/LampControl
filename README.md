Lamp Control
===========

Turn on lamps, powered rails and **shelves (étagères)** by hand or with WorldEdit!

- Right-click a redstone lamp / powered rail with an empty hand to switch it on/off without redstone. Everyone can do it by default (`lampcontrol.use`).
- Right-click a shelf with an empty hand to switch its *powered* look on/off. Sneak + right-click to take items back from the shelf. Powered shelves facing the same way connect (3 max) and swap the hotbar like vanilla.
- `/lamp` or `//lamp` (WorldEdit selection) turns lamps and shelves on, `/lamp off` turns them off.

Requires Paper 26.3 and Java 25. Build with `mvn package`.

Bukkit-dev: [here](https://dev.bukkit.org/bukkit-plugins/lampcontrol/)
